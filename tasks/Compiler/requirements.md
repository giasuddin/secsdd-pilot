# Requirements Document

## Introduction

Compiler feedback app (CompilationNow).

## Requirements

### Requirement 1: Attempt to compile file and returns whether compilation succeeds and if present, compiler errors

**User Story:** As a client, I want to attempt to compile file and returns whether compilation succeeds and if present, compiler errors.

#### Acceptance Criteria

1. WHEN a client sends a POST request to /compile, THE SYSTEM SHALL attempt to compile file and returns whether compilation succeeds and if present, compiler errors.
